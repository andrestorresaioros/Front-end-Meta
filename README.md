# Front-end Meta

Ejercicios del programa de desarrollo frontend de Meta, organizados por tecnología.

## Contenido

- HTML/ — estructura semántica, formularios y accesibilidad básica
- css/ — selectores, modelo de caja, flexbox y grid
- JS/ — sintaxis de JavaScript, funciones, objetos y manipulación del DOM

## Objetivo

Reforzar los fundamentos del desarrollo frontend con ejercicios cortos y autocontenidos, previos al trabajo con frameworks.

## Ejecución

Cada ejercicio es una página independiente. Abrir el archivo HTML correspondiente en el navegador, o servir la carpeta:

    python -m http.server 8000
